Burst, then load burst_then_load

A burst lands on a fresh key, then steady traffic follows on the same key, so the load starts on an emptied bucket.

Load
100 requests fired together at about 2 s, then 100 req/s from 3 s for 30 s
Port
8080 (HAProxy http mode, balanced per request)
API instances
3

Expected

  • /naive: All 100 of the burst
  • /basic: All 100 of the burst
  • /robust: About 20 of the burst, then 100 req/s

Allowed requests per second

  • /naive
  • /basic
  • /robust
  • limit 100 req/s

/robust allowed by deciding layer

  • allowed, global
  • allowed, fallback

/robust rejected (429) by deciding layer

  • rejected (429), local
  • rejected (429), global
  • rejected (429), fallback
