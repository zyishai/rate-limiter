One connection vs many connections

Two clients with their own keys run in parallel through the per connection frontend. One keeps a single connection busy, the other spreads its requests over 50 connections. The charts show each client separately.

Load
one_connection: 1 connection sending as fast as it can. many_connections: 500 req/s over 50 connections. 30 s
Port
8081 (HAProxy tcp mode, balanced per connection)
API instances
3

Expected

  • /naive: Everything, for both clients
  • /basic: About 100 req/s for one connection, about 300 req/s for 50
  • /robust: About 100 req/s for each client
